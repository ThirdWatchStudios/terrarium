# Department-era UI component library v1

Status: **approved Terrarium production-design source; Unity deferred**

This package extends the approved department-era UI source into reusable
carrier, control, Build-family, and literal-screen compositions. It is a visual
and machine-readable construction contract for the later joint Unity pass; it
is not runtime UI code.

The component library reuses the approved palette, Direction B typography,
five shared canonical marks, 19 canonical department glyphs, and current
canonical department-machine geometry. The approved six action/facing marks
and four cursor silhouettes now resolve from canonical Terrarium SVG sources;
the cursor hotspot contract lives beside them in the source manifest.

This source promotion does not authorize browser export, Unity import,
UXML/USS implementation, runtime binding, or cursor texture handoff.
