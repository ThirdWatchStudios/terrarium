# Canonical UI shared primitives v1

Status: **canonical artist-editable source art; production-wired in Terrarium**

These five SVGs are the approved UI-E1 source-authority batch. They own only
stateless shared shapes. Stable ids, tintable/literal modes, labels, export
paths, PNG ladders, Unity receiver contracts, carrier layout, focus placement,
text, accessibility, and interaction remain outside the SVGs.

The source split follows the accepted UI-E1a proof:

- exact authority inversion: `ui-divider`, `iris-mark`, `quotaco-mark`;
- approved redesign: square `ui-corner` and four-tick `ui-focus`.

The source SVGs are not generated by ordinary commands. Edit them directly,
then deliberately refresh the disposable TypeScript receiver:

```bash
npm run ui-shared:import
npm run ui-shared:import:check
```

`npm run assets:check` performs the read-only freshness check. It never repairs
or rewrites the canonical source bank.

## Source contract

- Canvas: `128 × 128`, `viewBox="0 0 128 128"`.
- Every visible path is directly under one canonical `translate(64 64)` group.
- Tintable sources contain white geometry only; Unity or another receiver owns
  the applied color.
- Literal sources own their final colors.
- Scripts, events, external references, raster images, rendered text,
  `foreignObject`, nested viewports, and path transforms are forbidden.
- Amber remains Capture-only and rose remains emotion-only.

The corresponding production-font direction is not packaged here. Typography,
font assets, and USS assignments are Unity-owned under catalog family F-02.
