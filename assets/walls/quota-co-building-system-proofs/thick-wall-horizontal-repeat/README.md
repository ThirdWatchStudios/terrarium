# QuotaCo N×2 thick-wall horizontal repeat proof

This external proof bank contains the two owner-accepted fixed-light middle
sources for a solid wall mass that grows horizontally:

- `filled_n_middle-*` directly resolves `mask_31` in the rear row.
- `filled_s_middle-*` directly resolves `mask_38` in the foreground row.
- `filled_s_middle-base.svg` is a byte-identical reuse of canonical
  `full_n_straight-base.svg`; its inherited generic title and description are
  intentionally preserved so the exact source reuse remains auditable.
- The accepted matrix is `20 31 26 / 16 38 34`; the accepted 2×2 corner family
  remains the control and both middle columns may repeat.
- The rear source owns the north outline, cream top, and coping highlight only.
- The foreground source owns the south material shade, coral register, green
  frontage, plinth, and floor-contact shade only.
- The foreground source keeps one subtle right-edge service seam so every
  repeated fascia cell has one owner; the rear top remains seamless.
- Neither source owns a cap, rollover, or buried rail.

Both masks are owner-accepted direct proof-layer sources. At this family's
acceptance checkpoint the ledger recorded 10 direct, 9 derived, 28 synthetic,
and 0 unresolved rows; later source-family decisions supersede those counts.
This acceptance does not register canonical or production stems, frame
identities, templates, exporter routes, atlas frames, schema values, blob
mappings, or Unity assets.
