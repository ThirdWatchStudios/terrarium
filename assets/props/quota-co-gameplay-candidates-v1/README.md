# QuotaCo gameplay-system prop candidates v1

Status: **visually accepted source-only concepts; not registered or exported**

These genuine, artist-editable SVG files preserve the accepted rated-state
concept art for four props whose live registration depends on a separate
gameplay-system and contract decision:

| Concept | Projection | Placement | Source |
| --- | --- | --- | --- |
| Exterior HVAC condenser | elevation | floor | `hvac-condenser.svg` |
| Surveillance camera | elevation | wall-slot | `surveillance-camera.svg` |
| Surveillance sensor | elevation | wall-slot | `surveillance-sensor.svg` |
| Privacy hedge | elevation | floor | `privacy-hedge.svg` |

Every file uses a `0 0 128 128` canvas, title/description metadata, and ordinary
semantic editor groups. They are deliberately not included in the production
prop importer, `PROP_TEMPLATES`, facility catalog, schema, exports, or Unity
registration. Their degraded and inoperative states remain accepted proof
geometry and will become editable state sources only when the corresponding
gameplay receivers and live IDs are approved.
