# Canonical Bob production validation v2

Post-approval validation for the first source-owned fitted hairstyle. The production resolver (P) must remain identical to an independent fit of the three canonical Bob SVG facings (S) through the six declarative head envelopes.

- `01-six-head-directions.png`: production beside independently derived source geometry for all six heads and three authored facings.
- `02-literal-scale.png`: production (P) and source-derived (S) renders at literal 48 px and 32 px.
- `metrics.json`: source ownership, transform, coverage, parity, and deterministic audit.

The old code-drawn Bob builder is not part of this route. This validation adds no recipe, export-schema, runtime-fit, animation, or Unity state.
