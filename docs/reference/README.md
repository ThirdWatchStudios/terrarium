# Art-direction reference studies (authoring mirrors)

Owner-approved concept studies, mirrored here from the sim repo so the authoring bench has them
beside the masters. The canonical copies and their approved-intent notes live in
`The-Water-Cooler/docs/design/assets/art-direction/`; the written contract in
`The-Water-Cooler/docs/design/quota-co-high-oblique-art-direction.md` is the authority. **These images are
felt/family references, never production truth and never source pixels** — when an image and the written
contract disagree, the written contract wins.

## Inventory

- `quota-co-high-oblique-golden-room.png` — the felt target: high-oblique room read, chunky coordinated
  product language, controlled color, low near-wall cutaway.
- `quota-co-office-geometry-study.png` — the geometry family: floors, full/low walls, openings, partitions,
  junctions; continuous cream / coral / green banding. Panel frames, shadows, and raised-plinth floors are
  presentation only.
### Primary wall-kit target set — owner-approved 2026-07-20

- `quota-co-wall-module-family-study.png` — required full/low straight, end, corner, height-step,
  step-corner, T-junction, and door-junction vocabulary;
- `quota-co-wall-corners-and-ends-study.png` — authoritative west/east end profiles and
  northwest/northeast/southwest/southeast orientation map;
- `quota-co-wall-long-run-orthographic-study.png` — strict screen-axis long-run and installed-corner read;
- `quota-co-wall-directional-profile-study.png` — authored directional surface exposure and overhang;
- `quota-co-wall-long-run-continuity-study.png` — substantial molded construction, continuous silhouette,
  and modular-seam rhythm; its slight perspective convergence is presentation drift, not camera authority.

For wall work, these five newer sheets are the primary visual comparison set. Use the corners-and-ends sheet
to identify the target asset before editing; use the long-run orthographic and directional-profile sheets for
projection; use the long-run continuity sheet only for continuity and construction feel. The canonical
interpretation is `The-Water-Cooler/docs/design/assets/art-direction/quota-co-wall-reference-set.md`.

Band-grammar note for authors: the approved studies band walls **cream shell → coral chair-rail → deep
green field → charcoal plinth**, with vertical module seams. The §6 wall contract lists "cream shells, green
bases, teal fields, and coral bands" as the elements that must continue cleanly across compatible modules —
so any band-height change made on one straight must roll across every connected piece in the same batch.
