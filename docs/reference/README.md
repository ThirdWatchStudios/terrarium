# Art-direction reference studies (authoring mirrors)

Art-direction concept studies kept beside the masters for the authoring bench. The initial room, geometry,
and wall studies are mirrored from the sim repo; their canonical copies and approved-intent notes live in
`The-Water-Cooler/docs/design/assets/art-direction/`. Later product-family explorations are retained locally
as working Terrarium references. The written contract in
`The-Water-Cooler/docs/design/quota-co-high-oblique-art-direction.md` remains the authority. **These images are
felt/family references, never production truth and never source pixels** — when an image and the written
contract disagree, the written contract wins.

to identify the target asset before editing; use the long-run orthographic and directional-profile sheets for
projection; use the long-run continuity sheet only for continuity and construction feel. The canonical
interpretation is `The-Water-Cooler/docs/design/assets/art-direction/quota-co-wall-reference-set.md`.

### Product-family exploration set — retained 2026-07-22

These owner-positive working studies explore how the approved QuotaCo construction language bends across
floors, workstations, processing machines, and amenities. They are direction references, not production
sprites or exact facing/state geometry authority:

- `quota-co-floor-fields-and-thresholds-study.png` — calm carpet, resilient tile, sealed concrete, and rubber
  service fields; flush material transitions, circulation inlays, doorway thresholds, and service access. Its
  isolated metal-transition panels carry slight diagonal presentation drift, so use the installed composition
  for material hierarchy and keep production seams strictly screen-axis aligned.
- `quota-co-molded-plastic-workstation-study.png` — the preferred heavy 1970s workstation direction: thick
  cream rollover shells, integrated green pedestal pods, flush putty/olive/teal writing fields, and human-use
  overlays instead of broad wood tops. The plain left construction is the everyday baseline; the rear-spine
  version is the more equipment-heavy sibling.
- `quota-co-processing-series-study.png` — administrative-machine scale ladder, visible paper intake/output,
  service access, comparator facings, and idle/working/jammed swap-twin language. The large report comparator
  is the strongest family anchor; the vertical rack trends more modern-server and is not a settled rack target.
- `quota-co-amenities-series-study.png` — softer washable shells for cooler, coffee station, vending,
  refrigerator, lockers, waste station, break furniture, and planter, plus clean-versus-used social context.
  The transparent cooler bottle remains the most open material/form decision in the sheet.

The earlier broad wood-top workstation generation is intentionally not retained here; the molded-plastic
study supersedes it as the current working direction.

### UI component-language exploration — retained 2026-07-24

- `quota-co-ui-abstracted-administrative-study.png` — the current preferred UI direction: smoked olive and
  putty surfaces with the material memory of hanging-file folders, abstracted into integrated index chassis,
  offset label rails, unequal action groups, contained manila document fields, and cold IRIS insert/overwrite
  logic. Use it for material hierarchy, carrier separation, and component construction—not exact copy,
  layout, metrics, state semantics, or runtime component inventory. The all-cream floor-blending study,
  generic black/navy SaaS dark mode, and literal folder/envelope skeuomorphism are intentionally not retained.

Band-grammar note for authors: the approved studies band walls **cream shell → coral chair-rail → deep
green field → charcoal plinth**, with vertical module seams. The §6 wall contract lists "cream shells, green
bases, teal fields, and coral bands" as the elements that must continue cleanly across compatible modules —
so any band-height change made on one straight must roll across every connected piece in the same batch.
